## Por que essa referência é importante?

O Next.js passou a ser uma base essencial para aplicações web modernas, especialmente para projetos que exigem performance, SEO e bons padrões de estrutura.

A documentação oficial continua sendo uma referência indispensável para entender routing, server components, rendering e deploy.

## O que aprender aqui

- App Router
- renderização no servidor e no cliente
- metadata e SEO
- otimizações de imagem e carregamento
- deploy em plataformas modernas

É uma base sólida para quem quer construir sites e aplicações com boa experiência de uso e disciplina técnica.
